01 Pertidaksamaan

Linear: kerjakan kedua ruas. ×/÷ bilangan negatif ⇒ arah tanda dibalik.

−5 ≤ 2x+6 < 4 ⇒ −11/2 ≤ x < −1

Interval: [ ] ikut (≤, ≥); ( ) tidak (<, >); ±∞ selalu ).

Kuadrat: semua ke kiri ⇒ faktorkan ⇒ akar di garis bilangan ⇒ uji tanda.

a > 0: + di luar akar, − di antara akar; a < 0: kebalikannya

x²−x−6 < 0 ⇒ (x−3)(x+2) < 0 ⇒ −2 < x < 3

Nilai mutlak (a>0): |x|<a ⇒ −a<x<a; |x|>a ⇒ x<−a atau x>a.

02 Fungsi kuadrat

y = ax²+bx+c · xv = −b/(2a)
yv = f(xv) = c − b²/(4a)

a > 0: terbuka ke atas, minimum, range [yv, ∞). a < 0: ke bawah, maksimum, range (−∞, yv].

Sketsa: akar · potong y=(0,c) · vertex · sumbu x=xv · arah buka. Labeli semua.

x = (−b ± √(b²−4ac))/(2a) · D=b²−4ac

x²+5x+6: akar −3,−2 · vertex (−5/2,−1/4) · range [−1/4,∞)

Domain: penyebut ≠0 · akar genap: isi ≥0 · log: isi >0. Range ≠ kodomain.

03 Fungsi, invers, komposisi

Fungsi: setiap input punya tepat satu output. Domain=input; kodomain=tujuan; range=output tercapai.

Injektif: f(a)=f(b)⇒a=b · Surjektif: range=kodomain · Bijektif: keduanya.

Invers: y=f(x) ⇒ selesaikan x ⇒ tukar variabel. Domain f−1 = range f.

(f∘g)(x)=f(g(x)) · urutan tidak boleh dibalik
(f∘g)−1 = g−1∘f−1

Jebakan: x² tidak injektif di ℝ, tetapi injektif di [0,∞).

04 Bilangan & akar

ℕ ⊂ 𝕎 ⊂ ℤ ⊂ ℚ ⊂ ℝ ⊂ ℂ · ℚ={a/b | a,b∈ℤ, b≠0}

Rasional: bisa a/b. Irasional: √2, π, e. √9=3 rasional; 0,75=3/4.

0 dan 1 bukan prima/komposit · 2 satu-satunya prima genap.

√(ab)=√a·√b · √(a/b)=√a/√b · √(a²)=|a|
(√a+√b)(√a−√b)=a−b · 1/√a=√a/a

05 Bilangan khusus

Floor/ceiling: ⌊3,5⌋=3, ⌈3,5⌉=4; ⌊−0,5⌋=−1, ⌈−0,5⌉=0. Jangan buang desimal.

a=mq+r · 0≤r<m · −25 mod 7=3

Log: y=logax ⇔ x=ay; a>0, a≠1, x>0. loga1=0, logaa=1.

Eksponen/faktorial: a0=1, a−n=1/an, 0!=1, n!=n·(n−1)!.

Rekursi: f(n)=n·f(n−1), basis f(0)=1.

07 Identitas

sin²x+cos²x=1 · 1+tan²x=sec²x · 1+cot²x=csc²x

tan=sin/cos · cot=cos/sin · sec=1/cos · csc=1/sin

sin(−x)=−sin x · cos(−x)=cos x · tan(−x)=−tan x

sin2x=2sinxcosx
cos2x=cos²x−sin²x=2cos²x−1=1−2sin²x
1−cos2x=2sin²x · 1+cos2x=2cos²x

Ingat: sin(−x)=−sinx. Lembar lama sempat menulis tanpa minus.

08 Limit aljabar

Limit ≠ f(c). Substitusi dulu; penyebut ≠0 ⇒ selesai. 0/0 ⇒ ubah bentuk.

limx→cf(x)=L ⇔ limx→c⁻f(x)=limx→c⁺f(x)=L

0/0: faktorkan · sekawan · samakan penyebut · identitas. 0/0 bukan jawaban.

x→∞: pangkat atas < bawah ⇒0
pangkat sama ⇒ rasio koefisien tertinggi
pangkat atas > bawah ⇒ ±∞

Kontinu: f(c) ada ∧ limit ada ∧ limit=f(c). Lubang · loncat · tak berhingga.

Penyebut 0 belum tentu asimtot; bisa lubang. Asimtot tegak jika meledak ke ±∞.

09 Limit trigonometri

limx→0 sinx/x=1 · limx→0 tanx/x=1
limx→0 (1−cosx)/x=0 · limx→0 (1−cosax)/x²=a²/2
limx→0 sin(ax)/x=a · limx→0 sin(ax)/sin(bx)=a/b

Syarat: radian. Teknik: munculkan sinu/u dengan u sama; tan⇒sin/cos; sec⇒1/cos.

tan5θ/sin3θ ⇒ (sin5θ/5θ)(3θ/sin3θ)(5/3)(1/cos5θ) ⇒ 5/3

(sin3t+4t)/(t·sect)=(sin3t/t+4)cost ⇒ (3+4)·1=7

Substitusi aman: limθ→π/2 θcosθ=(π/2)·0=0.
